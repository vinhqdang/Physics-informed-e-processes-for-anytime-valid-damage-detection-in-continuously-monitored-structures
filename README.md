# Physics-informed e-processes for damage detection under a lifetime false-alarm budget in continuously monitored structures

Manuscript package for the article of that title (first submitted as "Physics-informed
e-processes for anytime-valid damage detection in continuously monitored structures";
Artificial Intelligence for a Sustainable Built Environment, special issue
"Physics-Informed AI for Infrastructure Resilience"). The repository name keeps the
first-submission title.

| Path | Content |
|---|---|
| `main.tex`, `refs.bib` | LaTeX source of the manuscript (revised text in blue; `\CLEANBUILD` gives the clean version) |
| `figures/` | figures, including the vector source of Figure 10 (`fig_kw51.pdf`) |
| `code/` | simulation, monitors, Z24 and KW51 experiments, table generator |
| `revision/` | responses to the editor and reviewers, highlighted and clean PDFs |
| `supplementary/` | `phase_code.zip`, the code archive supplied with the submission (Supplementary file S1) |
| `README_reproduction.md` | stage-by-stage reproduction instructions and data provenance |
| `SUBMISSION_METADATA.txt` | title, abstract and keywords as they should appear in the submission system |

See `README_reproduction.md` for how to rebuild the PDF and rerun the experiments.
